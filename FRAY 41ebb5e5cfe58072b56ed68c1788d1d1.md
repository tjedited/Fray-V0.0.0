# FRAY

# Fray is a desktop platform that combines the integrated workflow of a multi-disciplinary creative suite with a low-level developer toolkit designed for power users.

## 01 Guiding UX Principles

Fray’s North Star of User Experience

![](https://images.unsplash.com/photo-1620121692029-d088224ddc74?ixlib=rb-4.1.0&q=85&fm=jpg&crop=entropy&cs=srgb)

**Smart**
The platform design maintains and promotes user freedom; it should never get in the way of the user.

**Transparent**
The platform exposes what it is doing to the user; it should never hide functionality or leave the user guessing.

![](https://images.unsplash.com/photo-1620121692029-d088224ddc74?ixlib=rb-4.1.0&q=85&fm=jpg&crop=entropy&cs=srgb)

![](https://images.unsplash.com/photo-1620121692029-d088224ddc74?ixlib=rb-4.1.0&q=85&fm=jpg&crop=entropy&cs=srgb)

**Affordable**
The platform value the user receives exceeds what they pay for it; it should never feel like a waste of money.

**Responsive**
The platform always reacts to user interaction; it should never feel static or frozen.

![](https://images.unsplash.com/photo-1620121692029-d088224ddc74?ixlib=rb-4.1.0&q=85&fm=jpg&crop=entropy&cs=srgb)

## 02 Core Design Features

<aside>
<img src="https://app.notion.com/icons/link_blue.svg" alt="https://app.notion.com/icons/link_blue.svg" width="40px" />

**Essentially Decoupled**
The front end, back end, and plug-in processes are vitally independent. If one component fails, it will not take the rest of the platform down with it.

</aside>

<aside>
<img src="https://app.notion.com/icons/swap-horizontally_blue.svg" alt="https://app.notion.com/icons/swap-horizontally_blue.svg" width="40px" />

**Experientially Integrated**
Interprocess communication and controls are exposed to the user. The experience of interacting with each process will feel instantaneous and seamless.

</aside>

<aside>
<img src="https://app.notion.com/icons/expand_blue.svg" alt="https://app.notion.com/icons/expand_blue.svg" width="40px" />

**Endlessly Expansive**
A powerful developer toolkit is built in. Users can create and customize plug-ins to make their software both functional and beautiful.

</aside>

<aside>
<img src="https://app.notion.com/icons/paint-brush_blue.svg" alt="https://app.notion.com/icons/paint-brush_blue.svg" width="40px" />

**Experimentally Expressive**
The platform is a versatile software foundation. Users can build, customize, and optimize whatever functionality they want on top of it.

</aside>
